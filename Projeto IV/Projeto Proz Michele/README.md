# 🧪 Espagiria Interativa

Um projeto experimental com carrossel de imagens ✨ e formulário com validação 🔐. Criado para fins educacionais e alquímicos! 🧙‍♀️

---

## 🚀 Funcionalidades

- 📸 **Carrossel de imagens** com título e descrição sobre o processo espagírico
- 🔄 Navegação entre imagens (botões de avançar/voltar)
- 📋 **Formulário de login** com validação de:
  - 📧 E-mail válido
  - 🔑 Senha com no mínimo 6 caracteres
- ❌ Exibição de mensagens de erro e destaque visual nos campos inválidos

---

## 🛠️ Tecnologias Utilizadas

- HTML5 🧱
- CSS3 🎨
- JavaScript Vanilla 🍦

---

## 📂 Estrutura de Arquivos

```
/espagiria-interativa
├── index.html
├── style.css
└── script.js
```

---

## 🧠 Como usar

1. Abra o `index.html` no navegador 🌐
2. Navegue pelo carrossel com os botões ⬅️ ➡️
3. Teste o formulário digitando e-mail e senha 💬
